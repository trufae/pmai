The useful differences

A personal agent.
A lot of possibilities.

Talk, build, explore. Native apps and a capable terminal, with conversations you can take with you.

01 / Voice mode · iOS + CLI

Less typing.
More talking.

Speak a question and hear the reply on iPhone. In the terminal, start a voice agent with /voice: choose realtime or walkie-talkie mode while your text prompt stays ready.

/voice realtime/voice walkie-talkie

iOS transcription stays on device by default; native live transcription needs iOS 26+ and an installed speech model. CLI voice uses your configured audio backends. Chat text goes to your selected model provider.

02 / Remote hosts · iOS + CLI

Your workstation, in your pocket.

Pair with a running pmai host and continue its saved chats, work across projects, and browse or transfer files. Share on your LAN or use encrypted OpenTunnel access across firewalls.

How remote pairing works ↗

03 / Portable conversations

Take the whole conversation.

Share a .pocketmai file through AirDrop, a local file transfer, or your own storage. Continue in PocketMai or import it in the CLI, with attachments, tool messages, and subagent chats.

No internet service is needed to transfer the file. Provider credentials stay behind; the receiving device uses its own models.

04 / Documents that leave the chat

From a reply to a real document.

Export conversations to Word, EPUB, Markdown, HTML, plain text, or JSON. Bring documents back in: read DOCX and EPUB, convert PDFs, or use OCR for scanned pages.

.docx.epub.md.html.json

05 / Fine-grained control

You set the boundaries.

Choose tools per agent and per MCP server. Set file and folder rules to allow, ask, or deny. Review or edit tool arguments, control network tools, and set limits on turns, tokens, time, and subagents.

Your prompts. Your skills. Your team.

Write reusable system prompts, create and import skills, and give each agent its own model and tools. Follow the subagent tree, read its work, send guidance, pause it, or stop a branch.

iOS

Make little apps

Create and run WebXDC mini apps with HTML, CSS, and JavaScript. Keep revisions, roll back, and share a .xdc for PocketMai or Delta Chat. The runner blocks network access.

iOS

A browser you can take over

Open a PiP WebKit browser. Let the agent read text or the DOM, use OCR, click, type, and scroll. Enlarge the card and take over whenever you need to.

iOS + CLI

Search and read the web

Search with a configured provider, fetch pages as readable content, and download files. Choose your search service, including a SearXNG instance.

iOS + CLI

Look inside GitHub

Read repositories, source files, PR diffs, commits, issues, releases, and CI logs. A configured token can grant access to private repositories. Posting comments, reviews, or pull requests requires write access and approval under your tool policy.

iOS + CLI

Your local knowledge index

Index project docs, source, and supported documents with vdb. Retrieve passages with paths and line references. Default retrieval uses local TF-IDF + BM25, without downloading an embedding model.

iOS + CLI

Work with your files

Read, search, write, and patch within your configured workspace. On iOS, browse and preview local or remote files, edit text, and upload or download documents.

iOS

Use your calendar

Read upcoming events or a date range. Enable event creation separately when you want the assistant to add an event, using native Calendar permissions.

iOS 26.1+

Set an actual alarm

Ask for a countdown, a one-time alarm, or a repeating weekday alarm through AlarmKit. List or cancel the alarms scheduled by PocketMai.

iOS + CLI

Check the weather

Get conditions and forecasts for a configured location. On iOS, opt into device location when it is useful.

iOS + CLI

Connect to Mastodon

Search posts and read a user’s recent updates on your chosen instance. Posting and replies require you to enable writes and configure credentials.

iOS · macOS CLI

Read images and scans

Extract text locally with Apple Vision. Import scanned pages without uploading them to an OCR service. Other CLI platforms can use an installed Tesseract.

iOS + CLI

Remember the project

Keep project memory and persistent todos. Organize saved conversations by workspace, search past chats, and reopen the context you need.

iOS + CLI

Add skills and MCP tools

Create, edit, and import SKILL.md skills. Connect remote Streamable HTTP MCP servers; the CLI also supports local stdio servers and native plugins.

CLI

Serve and compose agents

Use ACP agents as providers or subagents. Serve pmai over ACP or expose its selected agent through MCP, retaining its configured model, tools, and limits.

iOS + CLI

Supervise the agent tree

Inspect subagent transcripts, status, and usage. Give each agent a role, model, and tool set. Steer ongoing work or stop a branch.

iOS + CLI

Edit the context

Edit, undo, trim, search, or compact a conversation with a focus. Use a separate compaction model and keep linked tool-call transactions valid.

Your resources, your rules

Make the choices
that matter.

Choose the model and the tools, then decide how much autonomy to give them.

Pick your inference.

Use Apple Intelligence or MLX on supported Apple hardware, a local Ollama or llama.cpp endpoint, or an OpenAI-compatible API. Each agent can use a different provider.

Grant access deliberately.

Set per-resource file rules and per-tool policies, choose manual or model-assisted approval, and edit arguments before execution. Enforce run budgets and turn off internet tools when working offline.

What can stay offline?

With a local model and local tools selected, conversations, project memory, document retrieval, and supported OCR can run without an internet service. On-device speech requires supported, installed language assets. Remote providers, web tools, and remote hosts need their respective connections. The CLI’s airplane setting limits tools; it does not disconnect the selected inference provider.

How far does the sandbox extend?

Files and local document retrieval enforce workspace boundaries, path rules, and resolved symlink checks. iOS also runs within its app sandbox and system-granted resources. CLI shell commands run with the privileges of the pmai process and their own approval rules; file-tool policies are not an OS sandbox for shell commands.

Can I move a chat without exporting my API keys?

Yes. A .pocketmai conversation file includes the conversation and embedded attachments, including tool messages and nested agent chats. It excludes provider credentials and diagnostic reports. Transfer the file without internet using AirDrop or local storage, then continue with the receiving device’s configured provider.

Does the Mac app share my terminal chats?

Yes. pmai for Mac uses the CLI’s existing projects, saved conversations, and configuration. Open a workspace to find your chats, or use Open in Terminal to continue there. The Mac interface requires macOS 15+; iOS-specific features, including its live voice interface, are not included.

Are all features available on Android?

The Android app uses Kotlin and Jetpack Compose with the shared MaiCore engine. It includes streaming chat, saved conversations, photo and document attachments, local tools, HTTP MCP, skills, remote hosts, and WebXDC apps. In-app voice and on-device models are not available yet. The Pebble bridge supports watch dictation and saved shortcuts through the connected Pebble phone app. See the Android guide for platform details. The separate Android CLI provides the terminal agent feature set.
