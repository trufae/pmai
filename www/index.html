The useful differences

A personal agent.
A lot of possibilities.

Native device features, a capable terminal, and conversations you can actually take with you.

01 / Local voice · iOS

A conversation you can speak.

Talk, listen to replies, or attach a voice note. Transcription stays on device by default. Choose a local model and device voice for an offline conversation.

Native live transcription needs iOS 26+ and an installed speech model. Your selected model provider receives the resulting chat text.

02 / Remote hosts · iOS + CLI

Your workstation, in your pocket.

Pair with a running pmai host and continue its saved chats, work across projects, and browse or transfer files. Share on your LAN or use encrypted OpenTunnel access across firewalls.

How remote pairing works ↗

03 / Portable conversations

Take the whole conversation.

Share a .pocketmai file through AirDrop, a local file transfer, or your own storage. Continue in PocketMai or import it in the CLI, with attachments, tool messages, and subagent chats.

No internet service is needed to transfer the file. Provider credentials stay behind; the receiving device uses its own models.

04 / Documents that leave the chat

From a reply to a real document.

Export conversations to Word, EPUB, Markdown, HTML, plain text, or JSON. Bring documents back in: read DOCX and EPUB, convert PDFs, or use OCR for scanned pages.

.docx.epub.md.html.json

05 / Fine-grained control

You set the boundaries.

Choose tools per agent and per MCP server. Set file and folder rules to allow, ask, or deny. Review or edit tool arguments, control network tools, and set limits on turns, tokens, time, and subagents.

What the controls cover ↗

06 / An agent you can shape

Your prompts. Your skills. Your team.

Write reusable system prompts, create and import skills, and give each agent its own model and tools. Follow the subagent tree, read its work, send guidance, pause it, or stop a branch.

Choose separate models for chat, compaction, tool decisions, and approval review.

Your resources, your rules

Make the choices
that matter.

Choose the model and the tools, then decide how much autonomy to give them.

Pick your inference.

Use Apple Intelligence or MLX on supported Apple hardware, a local Ollama or llama.cpp endpoint, or an OpenAI-compatible API. Each agent can use a different provider.

Grant access deliberately.

Set per-resource file rules and per-tool policies, choose manual or model-assisted approval, and edit arguments before execution. Enforce run budgets and turn off internet tools when working offline.

What can stay offline?

With a local model and local tools selected, conversations, project memory, document retrieval, and supported OCR can run without an internet service. On-device speech requires supported, installed language assets. Remote providers, web tools, and remote hosts need their respective connections. The CLI’s airplane setting limits tools; it does not disconnect the selected inference provider.

How far does the sandbox extend?

Files and local document retrieval enforce workspace boundaries, path rules, and resolved symlink checks. iOS also runs within its app sandbox and system-granted resources. CLI shell commands run with the privileges of the pmai process and their own approval rules; file-tool policies are not an OS sandbox for shell commands.

Can I move a chat without exporting my API keys?

Yes. A .pocketmai conversation file includes the conversation and embedded attachments, including tool messages and nested agent chats. It excludes provider credentials and diagnostic reports. Transfer the file without internet using AirDrop or local storage, then continue with the receiving device’s configured provider.

Are all features available on Android?

The Android app is a native chat preview with provider and model setup, custom system prompts, streaming replies, saved conversations, and light/dark themes. Voice, tools, MCP, attachments, OCR, local inference, and remote host navigation are not in that app yet. The separate Android CLI provides the terminal agent feature set.
